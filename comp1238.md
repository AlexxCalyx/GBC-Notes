# Weekly Recap

## Week 1 Writing, Text, and the History of Computing

- Computers have a long history of being used to store, process, and communicate information.
- Writing and text are fundamental ways of representing information.
- Computers ultimately need ways to represent written characters as data.
- **Monospaced fonts** give every character the same amount of horizontal space.
  - Example: `i` and `W` occupy the same width.
  - Commonly used for programming, terminals, and ASCII art.
- **Proportional fonts** give different characters different widths.
- ASCII art relies heavily on monospaced fonts so that characters line up correctly.
- Text representation and formatting are important foundations for working with computer data.

## Week 2 Bits, Bytes, Memory, and Number Systems

- A **byte** consists of **8 bits**
- **ASCII** is a system for representing characters using numerical values
- **RAM (Random Access Memory)** is generally:
  - Fast
  - Temporary
  - Volatile
  - Used as working memory
- **Storage** is generally:
  - Long-term
  - Non-volatile
  - Persistent when the computer loses power

## Week 3 Structured Text and Markup

- Markdown uses special characters to indicate formatting.
  - `#` can represent a heading.
  - `*` can be used for formatting or lists depending on context
- Special Markdown characters can be **escaped** using a backslash
  - Example: `\#` allows a literal `#` to appear instead of creating a heading
- **HTML** stands for **HyperText Markup Language**
- **JSON** is a structured text format commonly used to represent and exchange data.
- **XML** is another markup-based format for representing structured information.
- **Unicode** provides a much larger character set than older systems such as ASCII.
- **UTF-8** is a Unicode encoding.
  - Characters can require different numbers of bytes.
  - Common English ASCII characters use one byte in UTF-8.
- **Alphanumeric characters** consist of:
  - Letters
  - Numbers/digits
- Characters such as `%`, `?`, `*`, etc. are **non-alphanumeric**

## Week 4 Working With and Searching Text

- Keyboard shortcuts can make working with text significantly faster.
- **Modifier keys** change the function of another key.
  - Examples include `Ctrl`, `Shift`, and `Alt`
- Text editors are designed primarily for working with plain text.
- Examples of text editors include:
  - Notepad
  - Vim
  - VS Code
- **IDE** stands for **Integrated Development Environment**
- **Wildcards** represent unknown characters or sequences of characters when searching or matching.
- Common wildcard characters include:
  - `*`
  - `?`
  - Example:
    - `*.txt`
    - Can represent files whose names end in `.txt`.
- **Regular expressions (regex)** allow you to search for **patterns** in text.

## Week 5 Command Line Interfaces (CLI)

- **CLI** stands for **Command Line Interface**
- A CLI allows you to interact with a computer by entering textual commands
  - **CLI** — the command-line method/interface used to interact with the computer.
  - **Terminal** — provides an environment/window for interacting with the command line.
  - **Shell** — interprets commands and communicates with the operating system.
- Command lines remain useful because they can:
  - Be faster for some tasks.
  - Provide greater control.
  - Be useful for automation.
  - Be convenient for controlling remote computers
- Important CLI commands include:
  - `ls` — list files/directories.
  - `pwd` — show the current working directory.
  - `cd` — change directory.
  - `cat` — display/combine file contents.
  - `less` — view text interactively.
  - `cp` — copy.
  - `mv` — move or rename.
  - `mkdir` — create a directory.
  - `ping` — test communication with another system.
- A **pipe (`|`)** takes the output of one command and supplies it as input to another command.
- Example:
  - `ls -la | wc -l`
- **SSH** stands for **Secure Shell**
- SSH allows you to securely connect to and control a **remote computer**.
- SSH traffic is encrypted.
- **SCP** and **SFTP** can be used to securely transfer files between systems.
