# COMP1234 — Weeks 1–6 Midterm Study Guide

## Week 1 — How the Web Works

- **Web page:** A document displayed by a browser.
- **Website:** A collection of related web pages.
- **Client:** The browser or program requesting a resource.
- **Server:** The program or computer responding to a request.
- **Request:** A message asking a server for something.
- **Response:** What the server sends back.
- **HTML:** Defines content and structure.
- **CSS:** Controls appearance and presentation.
- **JavaScript:** Adds behaviour and interactivity.
- **URL:** Identifies a resource. In `https://student.example.com/about.html`, `https` is the protocol, `student.example.com` is the domain, and `/about.html` is the path.
- **HTTPS:** Encrypts the connection; it does not guarantee the website is trustworthy.
- **Developer Tools:** Inspect the page's current HTML and CSS. Changes made there are temporary and disappear when refreshed.
- **Local file:** A page on your computer is not publicly accessible simply because it opens in your browser.
- **index.html:** Common default filename for a site's home page.
- HTML is plain text. Use a text editor, not a word processor.
- A page can still display without CSS, but it looks unstyled.
- A page can still display without JavaScript, although JavaScript-dependent features may stop working.
- Each separate image, stylesheet or script may require its own browser request.

## Week 2 — Putting a Page Online

- **Web hosting:** A server makes your files available online.
- **Domain name:** A human-readable website name.
- **Registrar:** A company through which domain names are registered.
- **DNS:** Translates a domain name into an IP address.
- **Document root:** The server folder containing publicly accessible website files; commonly `public_html`.
- **SFTP:** Secure File Transfer Protocol, normally using port 22.
- **FTP:** Older file transfer protocol, normally port 21; plain FTP is unencrypted.
- **Upload:** Transfer a local file to the web server.
- **Cache:** A saved copy of a resource that a browser may reuse.
- **404 Not Found:** The requested resource is not found at that address.
- **Host key:** Used by an SFTP client to recognise a server.
- Saving a local file does not update the server; upload the changed file.
- A bare site address commonly serves `public_html/index.html`.
- Upload to the correct server folder and avoid accidentally adding an extra project folder.
- Use a hard refresh or private window to test whether an old page is cached.
- If an image or stylesheet is missing, open its own address. If it loads, inspect the path in the HTML; if it returns 404, inspect the server location and filename.
- HTTPS protects the connection, not the honesty of the website.

## Week 3 — Files, Folders, and Paths

- **Directory:** Another word for folder.
- **Parent directory:** The folder one level above the current folder.
- **File extension:** The ending identifying a file type, such as `.html`, `.css`, `.jpg` or `.png`.
- **Path:** Directions from one file or location to another.
- **Document-relative path:** Starts from the folder containing the current HTML document.
- **Root-relative path:** Starts with `/` and is resolved from the root of the website.
- **Absolute URL:** Includes the protocol and domain, such as `https://example.com/about.html`.
- **../:** Go up one folder.
- **index.html:** A file the server commonly serves when a folder's address is requested.
- Paths must match folder names, filenames, capitalization and extensions exactly.
- Use forward slashes `/` in web paths, including on Windows.
- Prefer lowercase filenames with hyphens instead of spaces.
- Beware of hidden extensions such as `index.html.txt`.
- A path in an HTML file is resolved from the HTML file's location; a URL inside a CSS stylesheet is resolved from the CSS file's location.

### Path examples

Assume the current page is `projects/index.html`:

- `href="about.html"` looks for `projects/about.html`.
- `href="../about.html"` looks for `about.html` one folder above `projects`.
- `href="/assets/img/photo.jpg"` starts at the website root.
- `href="https://example.com"` uses an absolute URL.

### Basic HTML skeleton

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>My Page</title>
</head>
<body>
  <h1>Welcome</h1>
  <p>Hello world!</p>
</body>
</html>
```

- `<!DOCTYPE html>` tells the browser to use HTML5; it is not an HTML element.
- `<html>` contains the document.
- `<head>` contains metadata and references to resources.
- `<body>` contains visible page content.
- `<title>` supplies the browser-tab title.
- `<meta charset="utf-8">` declares text encoding.
- **Element:** The complete HTML construct.
- **Tag:** Markup such as `<p>` or `</p>`.
- **Attribute:** Extra information inside an opening tag, such as `href` or `alt`.
- **Nesting:** Close the innermost element before closing its parent.
- Void elements such as `<img>` and `<meta>` do not need closing tags.

## Week 4 — Content and Meaning

### Headings and text

- **`<h1>`:** The main page heading. The course recommends one per page.
- **`<h2>` through `<h6>`:** Subheadings representing the document's structure.
- Heading levels describe hierarchy, not visual size.
- A sequence such as `h1, h2, h3, h2` is appropriate.
- Avoid skipping heading levels simply to change appearance.
- **`<p>`:** Paragraph.
- **`<strong>`:** Important content.
- **`<em>`:** Emphasized content.
- **`<br>`:** A line break where a break is part of the content.

### Lists

- **`<ul>`:** Unordered list; sequence does not matter.
- **`<ol>`:** Ordered list; sequence matters.
- **`<li>`:** An individual list item.
- A recipe's steps generally use `<ol>`; a shopping list generally uses `<ul>`.

### Links and images

```html
<a href="about.html">About me</a>
<a href="#contact">Jump to contact</a>
<h2 id="contact">Contact</h2>
<img src="photo.jpg" alt="A grey cat sleeping on a chair">
```

- **`<a>`:** Anchor element, used for hyperlinks.
- **`href`:** Holds the destination.
- **`id`:** Uniquely identifies an element on the page.
- **`#contact`:** Links to the element whose id is `contact`.
- Link text should make sense even when read outside its surrounding sentence.
- Avoid vague text such as "click here".
- **`target="_blank"`:** Opens the destination in a new tab.
- When opening a new tab, indicate "opens in a new tab" in the link text.
- **`<img>`:** Displays an image.
- **`src`:** Path to the image.
- **`alt`:** Text alternative for an image.
- Meaningful images need descriptive alt text.
- Purely decorative images use `alt=""`.
- Missing `alt` is not the same as an intentionally empty `alt`.

### Semantic HTML

- **`<header>`:** Introductory content.
- **`<nav>`:** Navigation links.
- **`<main>`:** Main content unique to the page; use one main region.
- **`<section>`:** A thematic group of content, generally with a heading.
- **`<article>`:** Content that can stand on its own.
- **`<aside>`:** Related but nonessential content.
- **`<footer>`:** Closing information.
- **`<div>`:** Generic container without its own semantic meaning.
- Semantic elements help readers, assistive technology and other tools understand page structure.

### Validation

- An HTML validator checks markup for errors and warnings.
- Fix the first reported error and validate again.
- An error may originate before the reported line.
- Valid HTML can still have poor link text, bad heading hierarchy or inappropriate alt text.

## Week 5 — Introducing CSS

### CSS structure

```css
p {
  color: red;
  font-size: 18px;
}
```

- **Selector:** `p` — chooses the elements.
- **Declaration:** `color: red;` — sets a style.
- **Property:** `color` — what is being changed.
- **Value:** `red` — the chosen setting.
- **Colon (`:`):** Separates property and value.
- **Semicolon (`;`):** Separates declarations.
- A missing semicolon between two declarations can invalidate both declarations.

### Three ways to attach CSS

1. **Inline:** `<p style="color: red;">` — affects one element.
2. **Internal:** `<style>...</style>` — styles one HTML page.
3. **External:** `<link rel="stylesheet" href="style.css">` — loads a separate stylesheet.

- Place the external stylesheet's `<link>` element inside `<head>`.
- An external stylesheet can be reused by multiple pages.
- `href` contains the stylesheet path.

### CSS selectors

```css
p { color: red; }
.note { color: green; }
#contact { color: blue; }
```

- **Element selector:** `p` — matches paragraph elements.
- **Class selector:** `.note` — matches elements with `class="note"`.
- **ID selector:** `#contact` — matches the element with `id="contact"`.
- **Universal selector:** `*` — matches all elements.
- Class names begin with a dot in CSS, not in the HTML class attribute.
- IDs begin with `#` in CSS, not in the HTML id attribute.
- A class can be reused on multiple elements; an id should be unique.

### Cascade and specificity

For ordinary declarations:

1. Inline style attribute
2. ID selector (`#id`)
3. Class selector (`.class`)
4. Element selector (`p`, `h1`)

- Higher specificity wins over lower specificity, even if written earlier.
- If two competing declarations have equal specificity, the later one wins.
- `!important` changes declaration priority and should not be used casually.

Example:

```css
#total { color: blue; }
p { color: red; }
```

For `<p id="total">`, the text is **blue** because the ID selector is more specific.

### Inheritance

- Text properties such as `color`, `font-family` and `line-height` commonly inherit from a parent.
- `border`, `background` and `width` generally do not inherit.
- A declaration applied directly to an element beats a value it would otherwise inherit.

### Common properties

- **color:** Text colour.
- **background-color:** Background colour.
- **font-family:** Font selection.
- **font-size:** Text size.
- **font-weight:** Boldness.
- **font-style:** Italic styling.
- **line-height:** Space between text lines.
- **text-align:** Horizontal text alignment.
- **text-decoration:** Decorations such as underlines.
- **text-transform:** Visual capitalization changes.

### Units and colours

- **px:** CSS pixels.
- **em:** Relative to the relevant font size.
- **rem:** Relative to the root element's font size.
- **%:** Percentage relative to the applicable reference value.
- **Hex colour:** `#RRGGBB`, such as `#ff0000` for red.
- **rgb():** Another way to specify colours.
- `line-height: 1.6` means 1.6 times the element's font size.
- Normal text should meet a contrast ratio of at least **4.5:1**.
- Large text should meet at least **3:1**.

## Week 6 — The Box Model

### Four layers of every element

From inside to outside:

1. **Content:** The text or image.
2. **Padding:** Space between the content and border.
3. **Border:** The line surrounding the padding.
4. **Margin:** Space outside the border.

**Remember:** Padding is inside. Margin is outside.

- Padding is appropriate when text needs room inside a coloured panel.
- Margin is appropriate when separate elements need space between them.
- Background colour covers content and padding, and extends beneath the border to its outer edge.
- The margin remains transparent.

### Calculating box width

Default `box-sizing` is `content-box`:

**Total visible width = content width + left padding + right padding + left border + right border.**

Example:

```css
.card {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

Total visible width = 200 + 20 + 20 + 5 + 5 = **250px**.

With `border-box`:

```css
.card {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

- The total visible width is now **200px**.
- The content width becomes **150px**.
- Padding and borders fit inside the declared width.
- Margin remains outside the visible border box.

A common stylesheet rule is:

```css
* {
  box-sizing: border-box;
}
```

### Borders

```css
.card {
  border: 2px solid #0f766e;
  border-bottom: 3px dashed blue;
}
```

- Border shorthand specifies thickness, line style and colour.
- Common line styles: `solid`, `dashed`, `dotted` and `none`.
- `border: 5px;` alone does not produce a visible border because the border style defaults to `none`.
- Individual sides can be styled using `border-top`, `border-right`, `border-bottom` and `border-left`.

### Margin collapse

```css
.top { margin-bottom: 30px; }
.bottom { margin-top: 20px; }
```

- The gap is **30px**, not 50px, because adjoining vertical margins can collapse.
- In this example, the larger margin determines the gap.
- Horizontal margins do not collapse.
- Margin collapse occurs under particular block-layout conditions, not in every layout situation.
- A first child's top margin can collapse through a parent with no top border or padding.
- Adding top padding or a top border to the parent can prevent that collapse.

### Centering

```css
.page {
  width: 700px;
  max-width: 100%;
  margin: 0 auto;
}
```

- `auto` left and right margins divide the available horizontal space evenly.
- A block element needs unused horizontal space for centering to be visible.
- A block that already fills the available width has no leftover space to divide.

### Block versus inline elements

**Block elements**
- Start on a new line.
- Generally fill the available width.
- Examples: `<p>`, `<h1>`, `<div>`, `<ul>`.
- Width, height, padding and margins affect layout.

**Inline elements**
- Sit within a line of text.
- Examples: `<a>`, `<span>`, `<strong>`, `<em>`.
- Usually occupy only the width of their content.
- Width and height do not apply in the usual way.
- Left and right padding/margins work.
- Vertical padding is painted but does not increase line height.
- Vertical margins do not create vertical spacing in ordinary inline formatting.

Use `display: block;` to make an inline element participate in block layout.

### Padding and margin shorthand

```css
padding: 20px;                /* all four sides */
padding: 10px 20px;           /* top/bottom, left/right */
padding: 10px 20px 30px;      /* top, left/right, bottom */
padding: 10px 20px 30px 40px; /* top, right, bottom, left */
```

- Four values go clockwise: **TOP, RIGHT, BOTTOM, LEFT**.
- The same shorthand patterns apply to `margin`.
- A later shorthand declaration can reset individual side values set earlier.

### Pseudo-classes

```css
a:hover { color: green; }
a:focus { color: blue; }
a:visited { color: purple; }
```

- **:hover:** Element under the mouse pointer.
- **:focus:** Element receiving keyboard or other input focus.
- **:visited:** Link already visited.
- Style `:hover` and `:focus` together when providing navigation feedback so keyboard users receive equivalent cues.

### Background images

```css
.hero {
  background-image: url("../img/texture.jpg");
  background-size: cover;
  background-repeat: no-repeat;
}
```

- CSS `url()` paths are relative to the stylesheet location.
- `cover` fills the background area, cropping if needed.
- `no-repeat` prevents the background from tiling.

### Developer Tools

- Inspect an element to see its actual box diagram.
- Read computed content, padding, border and margin measurements.
- Use the diagram to troubleshoot unexpected widths or gaps.
- Prefer padding and content-driven height for text panels instead of forcing a fixed height that may overflow.

# High-Priority Concepts to Remember

## HTML and web fundamentals

- HTML = structure/content; CSS = appearance; JavaScript = behaviour.
- Browser sends requests; server returns responses.
- HTTPS encrypts the connection, not the trustworthiness of the site.
- `index.html` is commonly the default home page.
- `public_html` is commonly the web server's document root.
- A 404 means the requested resource was not found.
- `<head>` contains metadata; `<body>` contains visible content.
- Attributes appear in opening tags; nested elements must close in the correct order.

## Paths and accessibility

- Document-relative: from the current document.
- Root-relative: from the website root, beginning with `/`.
- Absolute: complete URL with protocol and domain.
- `../` means go up one directory.
- CSS background-image paths are relative to the CSS file.
- `<ol>` for meaningful sequence; `<ul>` otherwise.
- Use semantic HTML and logical heading hierarchy.
- Use descriptive link text and appropriate image alt text.
- `alt=""` means intentionally decorative.
- `id` values must be unique.

## CSS essentials

- `selector { property: value; }`
- Class selector = `.`
- ID selector = `#`
- Stylesheet path attribute = `href`.
- External CSS uses `<link rel="stylesheet" href="style.css">`.
- Specificity: inline style > ID > class > element for ordinary competing declarations.
- Equal specificity: later declaration wins.
- Inherited values apply only when no direct declaration overrides them.
- `line-height: 1.6` means 1.6 times the font size.
- Normal text contrast: at least 4.5:1.

## Box model essentials

- Inside out: **CONTENT → PADDING → BORDER → MARGIN**.
- Padding is inside the border; margin is outside.
- Margin is transparent.
- Default `content-box`: declared width measures content.
- `border-box`: declared width includes padding and border.
- Default visible width = content + horizontal padding + horizontal borders.
- Vertical margins may collapse; horizontal margins do not.
- Four-value shorthand: **TOP → RIGHT → BOTTOM → LEFT**.
- `margin: 0 auto` centers a block when horizontal space remains.
- `:hover`, `:focus` and `:visited` describe element states.
- Developer Tools show the computed box dimensions.
